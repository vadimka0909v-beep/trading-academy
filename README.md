# Trading Academy

Образовательный сайт по трейдингу на русском языке. Статический сайт: React + Vite + Tailwind, маршруты через hash (`#/course`), прогресс хранится в localStorage этого браузера.

## Запуск

```bash
bun install
bun run dev      # режим разработки
bun run build    # сборка в dist/
```

## Публикация

Push в `main` запускает `.github/workflows/pages.yml`, который собирает сайт и публикует его на GitHub Pages.
Включите в настройках репозитория: Settings → Pages → Source: GitHub Actions.

## Важно

Учебные графики синтетические. Все цифры в примерах — учебные, не рекомендации. Видео и источники, которые ещё не проверены, помечены как таковые в интерфейсе.
